# Bulk Manager — SillyTavern extension

ลบ คัดลอก หรือสำรอง **บอท** **persona** และ **lorebook** ทีละหลายรายการ ติ๊กเลือกให้ครบแล้วกดครั้งเดียว ไม่ต้องเปิดทีละตัว

ตั้งแต่ v2.0.0 รวม **Lore Tidy** เข้ามาเป็นแท็บ **Lorebook** แล้ว (ดูหัวข้อ [Lorebook](#lorebook-เดิมคือ-lore-tidy)) ถ้าเคยติดตั้ง Lore Tidy ไว้ ถอนออกได้เลย การตั้งค่าแผง World Info จะย้ายมาให้เอง

- **ลบ** ดาวน์โหลดไฟล์สำรอง (.zip) ให้ก่อนลบ ตัวเลือกนี้ติ๊กไว้ให้ตั้งแต่แรก
- **คัดลอก** ทำสำเนาทุกตัวที่เลือก ใส่คำต่อท้ายชื่อสำเนาได้
- **สำรอง** ดาวน์โหลดเป็น .zip โดยไม่ลบอะไร
- **Lorebook** ดูว่าแต่ละเล่มถูกใช้ที่ไหน หาเล่มที่ไม่มีใครใช้แล้ว (เช่น เล่มที่ค้างจากการ์ดที่ลบไป) และเก็บกวาดลิงก์ค้าง

## ติดตั้ง

Extensions → Install extension → วาง URL ของ repo นี้

ทดสอบกับ SillyTavern 1.19.0

## เปิดใช้

- **บอท** ปุ่มรูปกระดาษซ้อน (layers) ข้างปุ่ม Bulk edit (รูปดินสอ) ใต้ช่องค้นหาในรายชื่อบอท
- **Persona** ปุ่ม **Bulk** ข้างปุ่ม Backup / Restore ในหน้า Persona Management
- **Lorebook** ปุ่มไม้กวาด 🧹 ในแผง World Info ถัดจากปุ่ม Import
- หรือพิมพ์ `/bulk` (บอท), `/bulk personas` หรือ `/bulk lore` (`/loretidy` ก็ยังใช้ได้)
- หรือไปที่ Extensions → Bulk Manager

## เลือก

- แตะทั้งแถวหรือที่ช่องติ๊กก็ได้
- **เลือกทั้งหมดที่แสดง** เลือกทุกตัวที่ตรงกับคำค้นตอนนั้น เช่น ค้น `สำเนา` แล้วเลือกทั้งหมดเพื่อลบสำเนาทิ้ง
- บนคอม กด Shift ค้างแล้วคลิกเพื่อเลือกเป็นช่วง
- ช่องค้นหาหาได้ทั้งชื่อและชื่อไฟล์ บอทเรียงตามชื่อหรือตามที่เพิ่มล่าสุดได้
- ป้ายข้างชื่อบอกว่า 💬 กำลังแชทอยู่ ⭐ favorite 👥 อยู่ในแชทกลุ่ม 🎭 persona ที่ใช้อยู่ 👑 default persona 🔒 ล็อกกับแชทนี้ 🔗 ผูกกับการ์ด
- ที่เลือกไว้ในแต่ละแท็บแยกกัน สลับแท็บแล้วยังอยู่

## ลบ

1. เลือก แล้วกด **ลบ** ตรวจรายชื่อกับคำเตือนอีกรอบ
2. บอทมีตัวเลือก **ลบแชทของบอทเหล่านี้ด้วย** (ติ๊กไว้ให้ เหมือนตอนลบใน SillyTavern เอง) ถ้าไม่ติ๊ก ไฟล์แชทจะยังอยู่ในโฟลเดอร์ chats
3. **ดาวน์โหลดไฟล์สำรองก่อนลบ** ถ้าอ่านไฟล์ไหนไม่ได้ จะยกเลิกทั้งหมดโดยยังไม่ลบอะไร

บอทลบผ่านคำสั่งลบของ SillyTavern เอง จึงล้างแท็กและข้อมูลอื่นของบอทให้เหมือนลบด้วยมือ แชทที่เปิดอยู่จะถูกปิดก่อนลบหนึ่งครั้ง

Persona ที่ใช้อยู่ตอนนี้จะไม่ถูกลบ ถ้าจะลบให้สลับไปใช้ตัวอื่นก่อน ถ้าลบ default persona ต้องตั้ง default ใหม่เอง

## คัดลอก

เลือก แล้วกด **คัดลอก** ช่อง **ต่อท้ายชื่อสำเนา** ใส่ได้ เช่น ` (สำเนา)` ถ้าเว้นว่าง สำเนาจะชื่อเหมือนต้นฉบับ (แบบเดียวกับปุ่ม Duplicate ของ SillyTavern) ดูความต่างได้จากชื่อไฟล์ใต้ชื่อ

ชื่อบอทคือ `{{char}}` และชื่อ persona คือ `{{user}}` ที่ส่งเข้า prompt คำต่อท้ายจะติดเข้าไปด้วย ถ้าไม่อยากให้ติด เว้นว่างไว้แล้วค่อยเปลี่ยนชื่อทีหลัง

- **บอท** สำเนาได้การ์ดทั้งใบพร้อมแท็กเดิม แต่ไม่ได้แชท
- **Persona** สำเนาได้รูป คำอธิบาย ตำแหน่ง/ความลึกใน prompt และ lorebook แต่ไม่ได้ผูกกับการ์ดที่ต้นฉบับผูกไว้ (เหมือน Duplicate ของ SillyTavern) ไม่อย่างนั้นสองตัวจะแย่งกันถูกเลือกอัตโนมัติ

คัดลอกเสร็จ สำเนาใหม่จะถูกเลือกไว้ให้ ถ้าคัดลอกผิดก็กด **ลบ** ต่อได้เลย

## Lorebook (เดิมคือ Lore Tidy)

ตอนเปิดแท็บนี้ จะเช็ค Chat Lore ในแชทของทุกการ์ดให้เอง ระหว่างนั้นจะลบไม่ได้ เพราะยังไม่รู้ว่าเล่มไหนผูกกับแชทอยู่บ้าง

ลบบอทแล้ว lorebook ของบอทนั้นไม่ได้ถูกลบไปด้วย ตอนยืนยันลบบอทจะบอกชื่อเล่มไว้ ลบเสร็จแล้วสลับมาแท็บ Lorebook จะเช็คใหม่ให้ และเล่มที่ไม่มีใครใช้แล้วจะขึ้นใน **ไม่มีใครใช้**

**ไม่มีใครใช้** คือเล่มที่ไม่ได้เป็นเล่มหลักหรือเล่มเสริมของการ์ดไหน ไม่ได้ผูกกับ persona ไม่ได้เปิดใน Global และไม่ได้เป็น Chat Lore ของแชทไหน

**ตามการ์ด** จัดกลุ่มเล่มตามการ์ดที่ใช้ มีรูปการ์ดกำกับ ติ๊กที่หัวกลุ่มเพื่อเลือกทุกเล่มของการ์ดนั้น เล่มที่ไม่ผูกกับการ์ดไหนรวมอยู่กลุ่มสุดท้าย

**ทั้งหมด** แสดงทุกเล่ม พร้อมป้ายบอกว่าใช้ที่ไหน
- 🌐 Global: เปิดไว้ใน Global World Info
- 👤 เล่มหลัก / เล่มเสริม: การ์ดที่ใช้เล่มนี้
- 🎭 Persona: persona ที่ผูกเล่มนี้
- 💬 Chat Lore: จำนวนแชทที่ผูกเล่มนี้ ชี้เมาส์เพื่อดูว่าแชทไหน
- 🧩 WIP: แชทที่เคยผูกเล่มนี้ผ่าน WorldInfoPlus

**ลิงก์ค้าง** เก็บกวาดข้อมูลที่ชี้ไปยังของที่ไม่มีแล้ว
- การ์ดที่ชี้ไปยังเล่มที่ถูกลบไปแล้ว ถ้าเป็นเล่มเสริมจะถอดลิงก์จากตรงนี้ได้เลย
- รายการเล่มเสริมของการ์ดที่ลบไปแล้ว ตอนลบการ์ด SillyTavern ไม่ได้ลบรายการนี้ในการตั้งค่า ล้างได้โดยไม่กระทบตัว lorebook
- ข้อมูลที่ WorldInfoPlus ทิ้งไว้ (ดูด้านล่าง)

ปุ่ม ✏️ ท้ายแถวเปิดเล่มนั้นในตัวแก้ไข ช่องค้นหาหาได้ทั้งชื่อเล่มและชื่อการ์ด

ลบ lorebook แล้ว จะถอดชื่อเล่มนั้นออกจากรายการเล่มเสริมของทุกการ์ดให้ด้วย

### ในแผง World Info

**ชื่อเล่ม Global** บนมือถือ ช่อง Active World(s) for all chats ขึ้นแค่ว่า "2 Items" จะแสดงชื่อเล่มที่เปิดเป็น Global ไว้ใต้ช่องให้เห็นเลย แตะชื่อเพื่อเปิดในตัวแก้ไข แตะ ✕ เพื่อถอดออกจาก Global บนคอมช่องนี้แสดงชื่ออยู่แล้ว จึงไม่แสดงซ้ำ

**Active World(s) for this chat** แสดงทุกเล่มที่ใช้กับแชทที่เปิดอยู่นอกจาก Global
- 💬 Chat Lore ของแชทนี้ แตะ ✕ เพื่อเลิกผูก
- 👤 เล่มหลักและเล่มเสริมของการ์ด ถ้าเป็นแชทกลุ่มจะแสดงของทุกตัวละครในกลุ่ม พร้อมชื่อตัวละคร
- 🎭 เล่มของ persona ที่ใช้อยู่
- ปุ่มข้างหัวข้อใช้ผูกหรือเปลี่ยน Chat Lore ของแชทนี้
- เล่มที่ถูกลบไปแล้วแต่ยังมีลิงก์ค้างอยู่จะขีดฆ่าไว้

ปิดทั้งสองส่วนนี้ได้ที่ Extensions → Bulk Manager

### ย้ายออกจาก WorldInfoPlus

WorldInfoPlus เก็บการผูก Multi Chat Lore ไว้ในการตั้งค่าของตัวเอง และล้างช่อง Chat Lore ของ SillyTavern ทิ้ง ถอน WorldInfoPlus แล้วข้อมูลนั้นยังอยู่

- เล่มที่ผูกกับแชทผ่าน WorldInfoPlus จะไม่ถูกนับเป็นเล่มที่ไม่มีใครใช้
- **ลิงก์ค้าง** มีรายการเล่มที่ WorldInfoPlus เปิดค้างไว้ใน Global กดถอดออกได้ในครั้งเดียว
- เปิดแชทที่เคยผูกไว้ แล้วมาที่ **ลิงก์ค้าง** จะเลือกเล่มแล้วผูกเป็น Chat Lore ของ SillyTavern ได้ (แชทละ 1 เล่ม เล่มที่เหลือให้เพิ่มเป็นเล่มเสริมของการ์ดแทน)
- ย้ายครบแล้ว กด **ล้างข้อมูล WIP ทั้งหมด** ได้

### ข้อจำกัด

- ไม่ได้เช็คแชทกลุ่ม ถ้าผูก Chat Lore ไว้ในแชทกลุ่ม เล่มนั้นอาจขึ้นว่าไม่มีใครใช้ ให้ดูให้ดีก่อนลบ
- การเช็คแชทต้องให้เซิร์ฟเวอร์อ่านไฟล์แชททุกไฟล์ ถ้ามีการ์ดหรือแชทเยอะมาก (โดยเฉพาะบนมือถือ) อาจใช้เวลาสักพัก ผลเช็คจะเก็บไว้จนกว่าจะเปลี่ยนแชทหรือแก้/ลบการ์ด
- entry ที่อยู่ในการ์ดเอง (embedded lorebook) ไม่นับ เพราะไม่ใช่ไฟล์ lorebook แยก

## ไฟล์สำรอง

**บอท** `characters-backup <วันที่>.zip`
- `characters/*.png` การ์ดเต็มใบ นำเข้าใหม่ด้วยปุ่ม Import character ได้ตามปกติ
- `chats/<ชื่อไฟล์บอท>/*.jsonl` แชทของบอท (มีเมื่อติ๊ก "ลบแชทด้วย" หรือกดปุ่ม **สำรอง**) เปิดแชทของบอทนั้นแล้วใช้ Import chat ได้

**Persona** `personas-backup <วันที่>.zip`
- `personas.json` รูปแบบเดียวกับปุ่ม Backup ในหน้า Persona Management ใช้ปุ่ม **Restore** นำกลับได้
- `User Avatars/*.png` รูป persona ปุ่ม Restore ของ SillyTavern อ่านแค่ไฟล์ .json ถ้าอยากได้รูปเดิมด้วย ให้คัดลอกรูปไปไว้ในโฟลเดอร์ `data/<user>/User Avatars/` ก่อนกด Restore

**Lorebook** `lorebooks-backup <วันที่>.zip`
- ไฟล์ .json แยกเล่ม แตกไฟล์แล้วใช้ปุ่ม Import ในแผง World Info ได้ตามปกติ

## ข้อมูลเก็บไว้ที่ไหน

Bulk Manager ไม่เก็บข้อมูลของตัวเอง นอกจากตัวเลือกแสดง/ซ่อนในแผง World Info ทุกอย่างอ่านจาก SillyTavern ตอนเปิด สิ่งที่ถูกเขียนมีแค่สิ่งที่คุณกดเอง คือ ลบ คัดลอก ถอดลิงก์ ถอดออกจาก Global และผูก Chat Lore
